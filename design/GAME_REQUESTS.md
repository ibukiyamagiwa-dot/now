# ゲームに入れること（たまってから、まとめて開発チャットへ）

書き方：調整したい数値は【名前】＝値 と書き、ゲームでは `DEF` などの外に出した値にする（あとで数値だけ直せるように）。

設定資料集で決まり、ゲーム側の作業が要るもの。資料集が固まってから、まとめて頼む。見た目と動きの見本は `design/v2/`（`bible2.html`、`moves.js`、`cards.js`）。ゲームは `css/`・`js/` に分かれているので、入れるときは `js/` 以下の該当する区画に合わせる（見本のコードをそのまま貼らない）。

## 入れ方
- **進め方（2026-11-25 Ibuki が決めた。判断シートの問1〜6）**
  - 絵の作り直しは、影の剣士 → 居合 → からくり → 小鬼 → イノシシ → 竜 の順に `?new` の骨組みを広げる（問1）。
  - 新しい技は全部入れる。ただし、入れる前に別のエージェントが見て、遊びごたえにほとんど貢献しない技やモーションは外す（問2）。結果と Ibuki の回答は各節の末尾の「レビューと Ibuki の回答」。外すと判断されても、合図の色・数・間のどれかを変えれば新しい問いになるので残せる（つばめ返し・弐の居合）。打ち合いのモーションは、数があるほど面白いので減らさない。
  - 「ひまなとき」は、コマンドを選ばずに【ひまなときまでの秒】（まず8秒）たったら、一度だけ見せる。「まもる」の意味は変えない（問3）。
  - 手触りで決める数字（影の【ふりのあとの間】、本気が居合を選ぶ割合など）は、セッションが台帳に仮の値で入れて進め、日報に数値を書く。Ibuki があとで調整盤で直す（問4）。
  - 赤い騎士まわりの5節（赤い騎士・本気／力みと削ぎ落とし／構えで何撃か の赤い騎士の分／赤の系統の打ち合い／打ち合いの見せ場）は「赤い騎士の作り直し」として一つに進める。構え → 技 → 打ち合い の順。門のぬしの2節（解錠の見分け・打ち合い）も「門のぬしの作り直し」にまとめる（問5）。
  - 「床と間合い」はテストで見張る（問6、定義はその節）。
  - 「まだ」の20節は、敵ごと・段ごとのチケット47枚に切った（`tickets/`）。節の状態はチケットから決まる（全部済めば済み、どれかが動けば途中）。
- 新しい絵は、いまの `?new`（`js/24r-rig.js`、資料集の骨組みの描き方。いまは門番だけ）を敵ごとに広げて入れる。作り直せた敵から順に、`?new` なしでも新しい絵にする（全員そろうまで待たない。途中は新しい絵と古い絵の敵がまざってよい）。どの敵が新しい絵になったかは、このファイルの各節に「（入れた）」と書く。

## 合図・軌跡
- 予兆→パリィの流れを核にし、合図は一回の攻撃ごとに、どの覚悟でも出す。連撃も一撃ごとに合図を置く。意図して間の速い連撃（前の当たりから28Fより短い撃）は二回当たる一回の攻撃として、続きの撃の合図はみならいだけ（【速い連撃の二撃目以降の合図】＝0）。構えで「どの攻撃が何撃来るか」を見せ、予兆が出ている間は体を止める（静）→最後に振る（動）。連撃の間（パリィのタイミング同士の間、ヒットストップは数えない）は技ごとに【連撃の間】として外に出す（いまの38〜50Fのまま。門番の二連撃は44F）。（入れた：`cue2K`＝0、`iv…`。古い絵は予兆までに構えを終えて止まり、最後の3Fで振る）
- 資料集の連撃を 2026-11-25 の決まりに合わせた（`DECISIONS.md` の「資料集の連撃の間」）。（入れた：【連撃の間】赤い騎士：三段突き＝36、【連撃の間】石なげ小鬼＝16・小鬼のおかしら＝13 を `DEF` に出した）まだゲームにない連撃は、入れるときに資料集の間で：【連撃の間】門のぬし：解錠（タン）＝44・（タタ）＝14、本気：十文字＝14、本気：参段（タン）＝44・（タタン）＝14、本気：つばめ返し＝42、第二形態：十文字と触手（タタン）＝14・（タン）＝44、第二形態：アーチの奥の指（最後の剣）＝44、赤い門のぬし：二つの高さ＝42、くらやみの竜：噛みつきから尾＝40、居合のおかしら：二の太刀＝44。目・触手・指・首に順に灯る技は、14Fの順に灯る合図をやめ、予告の連撃にする（`DECISIONS.md` の「予告の連撃」。予告→全部が引いて止まる→予兆は一撃目だけ→予告どおり。続きの合図はみならいだけ）。門の系統の3技は確定した（`chars/gate.md` の「数値」：兜の目→触手 28・28F、背中の触手 28・28F、門の向こうの指 28・14F）。赤の系統と三つ首の技は、その組の直し（T059・T062）で、ほかの予告の連撃と違うリズムに決める。合図は攻撃するもの（後ろの剣・触手の先・振り上げた鍵の先）に出す。解錠は「カチ（白）・カチ（赤）」を鍵の先の小さな光で見せ、予兆の光は引いた構えで出す。
- 抜き身の剣で斬る技の合図は、目ではなく剣先に出す（2026-11-25。`DECISIONS.md` の「合図は、攻撃するものに出す」）：本気の溜め・溜めの中のふり（本物）・伸び突き・二重フェイント（本物）、第二形態の水面の二重フェイント（本物）、居合のおかしらの二の太刀の二撃目（頭上の刀の先）。目に出すのは刃が鞘の中の技（居合・弐の居合・本気の返し斬り・くらやみの居合・居合の剣士）だけ。フェイントの紫の輪も剣先に出す（赤い騎士・本気・赤い門のぬし・第二形態のフェイント、二重フェイント、見抜かれる、溜めの中のふり。第二形態の水面の二重フェイントだけは映り姿の目）。本気の二重フェイントの本物は、八相へ上げきって止まってから光る：【二重フェイント：八相へ上げる時間】＝14F（合図の16F前から上げ始め、2F前に上げきる）。弐の居合の二撃目は、背後の納刀を合図の2F前に終えてから目が光る：【弐の居合：納刀から合図まで】＝2F。門のぬしの解錠は、鍵を引き終わった瞬間に最初の合図を出す（引く動きが合図をまたがない）。

## 赤い騎士・本気の赤い騎士
- 紫の輪（打ち合いの中は除く）でまもるを押したら、すぐ赤い光の本物（28F）（`r_seefeint` `r2_seefeint`）
- 返しの構え：斬りかかったら払って赤い光の返し斬り（28F、弾けば居合返し）（`r_kamae` `r_counter`）。本気は鯉口を切って刃が少し見える構えで、鞘で受けてから斬り下ろし（`r2_kamae` `r2_counter`）
- 本気の返し斬りとフェイントを見抜く一撃は、赤い角ばった軌跡（ふつうの赤い騎士の振りの軌跡）で描く
- 残心中に、こうげき・まもる・かいふく・まほうを押したら、もう一撃（赤、28F）。待てば構えを解く（`r_zanpunish`）
- 本気の技を足す：無音の居合（光らない、鞘の音から28F）、弐の居合（すれちがって後ろへ抜け、背後で納刀の音、後ろからもう一度。タン……タン）、溜め（引きのない両手突き。切っ先が動かない）、溜めの中のふり、伸び突き（赤・片手）、満月、つばめ返し（タン・タン）、十文字（赤い重い2撃、タタン、赤い角ばった軌跡）、参段（霞から上・中・下の飛ぶ斬撃、タン・タタン）。前に書いた「溜め居合」「抜き突き」は、この「溜め」「伸び突き」に変わった（下の「赤い騎士は力み、本気は削ぎ落とし」）
- **レビューと Ibuki の回答（2026-11-25〜26）**：つばめ返しは残し、二連撃（白の2撃・42F）と二撃目までの間を少しずらす（【つばめ返しの間】、仮の値はセッションが決めて日報に書く）。弐の居合も同じく間をずらして残す（すれちがう分だけ二撃目を遅らせる、【弐の居合の間】）。満月は残す。本気の主役は十文字にし、参段は十文字と拍が重ならないように作るか、手間が大きければ後回しにする。まとめる＝溜め（今の遅らせ突きを本気の絵に差し替える）、溜めの中のふり（溜めの中に確率で入る一つの技に）、伸び突き（今の赤い突きを本気の絵に差し替える）。　→ 決まった（11-26）：参段は後回し（資料集でも保留にし、赤の系統の確定を止めない）。

## 赤い騎士は力み、本気は削ぎ落とし（全部の技）
- 赤い騎士：肩をいからせた前のめりの構え。肩で速く息をし（約35Fで一往復）、ときどき柄をぎゅっと握り直す（肩が上がり切っ先がわずかに沈む）。振ったあとは勢いあまって前へ泳ぐ。切っ先は震わせない。二連撃は振りかぶりを背中に倒れるほど大きく、払いは両手で叩き払って体が前へ泳ぐ、フェイントは半歩踏み出して振りかぶりかける。合図から当たりまでの間は変えない。
- 本気を出す：マントを斬ったあと、剣を下ろして大きく一つ息を吐き、肩が落ちて低い正眼に構え直す（今は鞘に納めて居合の構えになっている）。
- 本気の赤い騎士の待機は、抜き身の剣を両手で握った低い正眼（切っ先は動かない、ゆっくり深い息、斬るときは腰が沈む）。鞘に納めた居合の構えは待機にしない。
- 居合は技を使うときだけ：居合・弐の居合・無音の居合（と返しの構え）だけ、正眼から剣を鞘に納める「チン」から始める。溜め居合→溜め（引きのない両手突き）、抜き突き→伸び突き（赤・片手）、参段の居合→参段（抜き身のまま）、二重フェイントの最後→八相からの赤い斬り下ろしに変える。居合を選ぶ割合を下げる。

## 剣は腕で振る（騎士の姿の敵すべて）
- 構えを移すときの腕と剣の角度は、近い回り道で補間する（半周をこえる差は体の後ろを大回りし、振っていない「ひと振り」が一瞬見える）。頭上を越える振りは、頭上を通るキーをはさむ。
- 手首だけで剣を回さない。手首の向き（剣−前腕）は親指側へ +0.45〜+2.4 ラジアン。手首を下へ折って剣を前腕より下げない。剣先を下げるときは肘を曲げ、腕ごと振り下ろす。振りかぶりは腕を頭上へ上げる。
- 振り抜く技は、当たりのあと5Fで、腕と剣がさらに振った向きへ進んで止まる（振り切り）。打ち合い・居合の一閃・参段・突き・連撃の途中は当たりの位置で止める。
- 本気の参段：霞の構え（両手を額の高さ、刃を水平）から、少し離れた位置で腕ごと三度振り抜き、大きな三日月の飛ぶ斬撃を上・中・下に飛ばす。
- 本気の満月：振り下ろしのあと、剣先が前で下りきってから両手を腰へ引きつける引き斬りで終える（肘は少し曲げ、腕は低く）。
- 当たりの瞬間は少し振り抜いたポーズで決め、振り切りで粘り、戻りは来た道をなぞらない（戻りの途中で剣先をいったん上へ逃がす）。
- 赤い騎士の二連撃：振り下ろしの勢いで剣先が床すれすれまで落ち、前足が半歩すべり、そのまま腕ごと斬り上げるV字にする（二撃目は振りかぶり直さない）。
- 本気の返し斬り：返しの構え（鯉口を切った居合の構え）から、抜きざまの下から上への斬り上げ。画面を大きく裂く角ばった赤い斬撃。最後に納刀。

- 専用ステージ：関所（覚悟0は門番。覚悟3・4は黒い門番の版で、格子が内側から不規則に押し曲げられている）、門前（くらやみの竜・三つ首の竜。遠くに通路と同じアーチの大門）、大門の間（封じた／開きかけ）、誓いの間（2つと、倒したあとの暗転）、穴の底（2つ）。ならくの奥の4つは資料集で描き直した版を使う（初版の赤い目・明るい紫のすき間・明るい金は使わない）。
- 落とし格子は黒い鉄のかたまり（棒3画素、横木は4本で棒の前を切れずに通る、光は棒のふちに1画素）。大門は鉄で留めた厚い板の扉で、遠い門前は板5画素で光にかすみ、近い大門の間は板11画素で重く暗い（光は合わせ目の細いもれと床ぎわだけ）。
- 例外：大門の間は重さを優先するので、ぬしの輪郭の差は 9 以上でよい（ぬしはくらやみのオーラで立たせる）。誓いの間は覚悟の光の外（くらやみのない別の世界線の部屋）。
