# ゲームに入れること（たまってから、まとめて開発チャットへ）

書き方：調整したい数値は【名前】＝値 と書き、ゲームでは `DEF` などの外に出した値にする（あとで数値だけ直せるように）。

設定資料集で決まり、ゲーム側の作業が要るもの。資料集が固まってから、まとめて頼む。見た目と動きの見本は `design/v2/`（`bible2.html`、`moves.js`、`cards.js`）。ゲームは `css/`・`js/` に分かれているので、入れるときは `js/` 以下の該当する区画に合わせる（見本のコードをそのまま貼らない）。

## 合図・軌跡
- いちばん大事な原則（構えを見れば来るものが分かる）を前提に、連撃の二撃目以降の合図を省けるようにする（技ごとに【二撃目以降の合図】＝あり／なし）。連撃の間（パリィのタイミング同士の間、ヒットストップは数えない）も技ごとに【連撃の間】として外に出す。同じ技なら固定、技がちがえば変えてよい。目安は10〜15F（いまのふつうの連撃は42〜50F）。省いた撃も「構えで止まる→最後の3Fで振る」で見えるようにする。
- 合図の光は剣先についていかず、光った場所に残す（全部の敵。`cards.js` の `cueAnchor`）。連撃の間は【連撃の間】として外に出し、手触りで調整する。
- 合図の光を大きくする（`cards.js` の `cueStar`：十字は半径最大10ドット、斜めの光、中心の白い芯、まわりのにじみ、表示18F。紫の輪は二重線）
- 剣の軌跡を2種類に：振る技は太い三日月の弧、突き・一文字・返し斬り・居合は細い一本線と速さの線（`arcTrail` `lineTrail`）
- 打ち合い：溜めの合は頭上からの大きな弧、詰めの合はまっすぐな突き

## 赤い騎士は力み、本気は削ぎ落とし（全部の技）
- 赤い騎士：肩をいからせた前のめりの構え。肩で速く息をし（約35Fで一往復）、ときどき柄をぎゅっと握り直す（肩が上がり切っ先がわずかに沈む）。振ったあとは勢いあまって前へ泳ぐ。切っ先は震わせない。二連撃は振りかぶりを背中に倒れるほど大きく、払いは両手で叩き払って体が前へ泳ぐ、フェイントは半歩踏み出して振りかぶりかける。合図から当たりまでの間は変えない。
- 本気を出す：マントを斬ったあと、剣を下ろして大きく一つ息を吐き、肩が落ちて低い正眼に構え直す（今は鞘に納めて居合の構えになっている）。
- 本気の赤い騎士の待機は、抜き身の剣を両手で握った低い正眼（切っ先は動かない、ゆっくり深い息、斬るときは腰が沈む）。鞘に納めた居合の構えは待機にしない。
- 居合は技を使うときだけ：居合・弐の居合・無音の居合（と返しの構え）だけ、正眼から剣を鞘に納める「チン」から始める。溜め居合→溜め（引きのない両手突き）、抜き突き→伸び突き（赤・片手）、参段の居合→参段（抜き身のまま）、二重フェイントの最後→八相からの赤い斬り下ろしに変える。居合を選ぶ割合を下げる。

## 剣は腕で振る（騎士の姿の敵すべて）
- 手首だけで剣を回さない。手首の向き（剣−前腕）は親指側へ +0.45〜+2.4 ラジアン。手首を下へ折って剣を前腕より下げない。剣先を下げるときは肘を曲げ、腕ごと振り下ろす。振りかぶりは腕を頭上へ上げる。
- 振り抜く技は、当たりのあと5Fで、腕と剣がさらに振った向きへ進んで止まる（振り切り）。打ち合い・居合の一閃・参段・突き・連撃の途中は当たりの位置で止める。
- 本気の参段：霞の構え（両手を額の高さ、刃を水平）から、少し離れた位置で腕ごと三度振り抜き、大きな三日月の飛ぶ斬撃を上・中・下に飛ばす。
- 本気の満月：振り下ろしのあと、剣先が前で下りきってから両手を腰へ引きつける引き斬りで終える（肘は少し曲げ、腕は低く）。
- 当たりの瞬間は少し振り抜いたポーズで決め、振り切りで粘り、戻りは来た道をなぞらない（戻りの途中で剣先をいったん上へ逃がす）。
- 赤い騎士の二連撃：振り下ろしの勢いで剣先が床すれすれまで落ち、前足が半歩すべり、そのまま腕ごと斬り上げるV字にする（二撃目は振りかぶり直さない）。
- 本気の返し斬り：返しの構え（鯉口を切った居合の構え）から、抜きざまの下から上への斬り上げ。画面を大きく裂く角ばった赤い斬撃。最後に納刀。

## 番人系統の桜井流の見直し
- 構えから当たりまで 6F を超える振りは、構えのまま止めて最後の 4F で振る。当たりで体（前傾・踏みこみ）を必ず動かす。
- 禍々しい者（黒い門番・暗い門のぬし・赤い門のぬし・第二形態）：合図の前にくらやみが武器へ吸い寄せられ、当たるとくらやみが噴き出して赤い目が一瞬開く。
- 門から指：三つ首の竜と同じ指（はがれた爪・金の指輪・節のしわ）で描き、指先の目が合図、引いてから突き出て、当たる瞬間に指先が口に裂ける。
- 連撃の静と動：一撃ごとに当たったポーズで3F止まり、次の構えへ素早く移って止まり、最後の3Fで振る。連撃の向きは説明文どおり（打ち下ろし・すくい上げ・突き）。
- くらやみの竜・三つ首の竜の連続攻撃にも止めを入れる（噛んだ形で止まる→次の構えへ素早く→止まる→噛む）。首のすり替えは、入れかわりが止まってから4F静止してから噛む。
- 三つ首の竜（と門から指）の三本の指に個性：上＝人差し指（細長い・せわしない・はがれた爪）、まん中＝中指（最長・太い・ゆっくり）、下＝親指（太く短い・低く前へ開き、口は前を向く・幅広の爪・金の指輪）。

## 間合い（カードとゲームのちがい）
- 資料集のカードは136幅に収めるため、主人公と敵の間を縮めて描いている。カード：主人公 x≈26・敵 x≈92（間66）、ゲーム：【HX】＝62・【EX】＝176（間114、約1.7倍）。絵の1画素の大きさは同じ。

  - イノシシの突進は、ゲームの位置の計算（boarX：遠いほど遅く着く）をそのまま使う。

## 主人公のモーション
- 資料集の主人公のページ（`heromv.js`）に合わせて、出現・待機・かいふく・こうげき（追撃・重い一撃）・ガード・パリィ・赤のパリィ・ジャスト回避・早押し・まほう3種・やられ・撃破を描き直す。受付の数値（【パリィの受付】6F、ジャスト回避12F、【ガードの受付】30F、【早押しの硬直】24F、【パリィ時のヒットストップ】12F、赤のパリィ18F、【追撃の受付】8F、【重い一撃の受付】3F）は今のゲームのまま。
- 主人公の剣の光・跡・火花はうすい青。追撃の×だけ金（今のゲームと同じ）。

## パリィされとブレイク
- 敵ごとに「パリィされ」の小（連撃の途中：刃がはね上がり、次の構えへつながる）と大（最後の一撃・赤：体ごとのけぞる）を入れる。今は全敵とも少し押し下がるだけ（`G.knock`）。見本は `design/v2/parried.js`（`g_pry` `r2_pry`、イノシシは `b_wall`）。
- ブレイクの崩れ姿（今の `'b'` の差分）を、資料集の崩れ待機に描き直す（`g_brk` `r2_brk` `b_brk`）。崩れ待機はくり返しで動かす。主人公の攻撃を受けたら、構えへ一気に戻る（`g_rec` `r2_rec` `b_rec`）。
- ブレイクの印：頭の上を回る金の星（`25-draw.js`）を、主人公の色（うすい青）の小さな星3つにする（金は打ち合いの合図の色なので紛れる）。光らせない。
- パリィされは敵ごと×攻撃する部位ごとに一つの決まり（技ごとには作らない）。振りと突きで分ける：振り＝はね上がってのけぞる、突き＝切っ先がそれて前へ泳ぐ（`knightKit`）。全員ぶんの見本は `parried.js`。
- くらやみに関わる者は、ブレイク中に胸からくらやみが漏れる（光らない）。第二形態のブレイクは本体だけ崩れ、水面の映り姿は崩れない。
- 弾かれた側のヒットストップの震え：横だけ、だんだん小さく。【パリィされの震え幅】＝小1.4・大2（ドット）

## 床と間合い（全部の敵）
- 剣先を床に刺さない（突き立てる姿は除く）。主人公に体を重ねない（すれちがう居合は除く）。見本は `cards.js` の `fixPose`。
- イノシシがひっくり返ったときは、背中を床につける（`mobs.js` の `drawBoarG`）。

## 影の剣士・うそつきの影
- 体は3段の影色（光らない、目なし）、剣だけ明るい灰紫。かかとから画面の外へ床の影の尾。兜は鍋形。うそつきの影は1.25倍（`v2/shade.js`）。
- 斬るときは踏みこまず、体が前へ「のびる」。フェイント（紫の輪）は、のびかけて止まり、輪郭がゆらいで縮む。
- フェイントは、ふりのあと構えに戻って止まってから次の合図（振っている最中に光らせない）。今のゲームの間（ふり pre14・pre6）より長くなるので、手触りを見て【ふりのあとの間】を決める。
- 覚悟の段の見た目（`SHV`）：影色、輪郭のゆらぎ、太い尾、開く目（光らない）。剣の色は変えない。
- 影の剣士にも「本物が2回続く」（今もある）。うそつきの影は「二重フェイント」（今もある）。
- 三つ首の竜のブレイク：指が止まり、指先の目がそろって裂け目の奥をふり向き、亡骸の頭が垂れる。戻りは一瞬でこちらを向く（`h_brk` `h_rec`）。
