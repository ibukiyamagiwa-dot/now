# 門の系統（門番・黒い門番・門のぬし・暗い門のぬし）

敵ごとの細部（見た目・技・モーション・パリィされ・ブレイクなど）。原則・作風・世界観・全員に通じる決まりは `design/DECISIONS.md` にあり、それを前提にする。決まったことだけを書く。
このファイルと `bannin.md`（番人系統の8体に通じる決まり）を合わせて読む。

## 門の系統
- 門番 → 黒い門番 → 門のぬし を、同じ土台（筒形の兜、紺と金の前垂れ、「閉じた門」の紋章）と、鎖（手首のかせ → 長く黒い鎖 → 門までつながる鎖 → ちぎれる）でつなぐ。

## 門の系統（第2版で決まったこと）
- 紺の前垂れは体の前に大きく見せる（胸からひざ下まで、金のふち）。門番は明るい紺、黒い門番は暗い紺、ぬしは色あせた紺にくらやみの染み、暗い門のぬしは破れて短い。
- 門のぬし（第一形態）にも、くらやみの要素を足す：封印のひびから走るくらやみの筋と、前垂れへのしたたり、紫の煙、マントの裾から這い出る触手。
- くらやみに関わるボス（黒い門番、門のぬし、暗い門のぬし）は、体のまわりにくらやみのオーラ（紫のにじみと、背中側のふちの光）を置き、暗い背景に溶けないようにする。
- 門のぬしは第一・第二形態とも書きこみを増やす（肩当ての鋲、角の金の輪、鎖かたびら、くらやみの筋）。
- くらやみに関わるボスには、新しい技と派生の立ち絵をどんどん足してよい。採用した新しい技：
  - 黒い門番：鎖の打ち払い、鎖の拍（床を3回打ち、次の拍で来る）
  - 門のぬし：門の重み（鎖を引いて門をきしませ、赤い光で叩きつける）
  - 暗い門のぬし：ちぎれた鎖の鞭、足元の溜まりから、扉のかみ合わせ（赤）、門の向こうの指（三つ首と同じもの）
- 採用した派生の立ち絵・演出：門番の登場（剣を打ち合わせて交差）、のまれかけ、目の数、鍵を床に突く、封印が脈打つ、門が口をあける、倒れると剣と黒い鎖が残る。
- 門のぬしの「赤い突き（一撃）」と「解錠（三撃）」は構えで見分ける。一撃＝鍵を体の後ろまで深く引いて腰を落とし、ぴたりと止まる（ひねらない）。解錠＝鍵を顔の前に立て、空中でカチ（白）・カチ（赤）と二回まわして見せる（まわすたびに光る）。見せた回数が、突きのあとのひねりの数。
- 門のぬし・暗い門のぬしの打ち合いは、いまのゲームの打ち合いの全部の場面にモーションを持つ：誘いのひと振り（金。弾くと二人が踏みこみ、画面の上下が締まり、鎖が張る）、溜めの合（鍵を頭上に掲げ、鎖が腕に巻きつく。頭上からの大きな弧）、詰めの合（振りかぶらず腰から鍵の歯で短く突く。線）、フェイント（鍵の輪が紫。振り下ろしかけて止め、引き戻す）、鍔迫り合い（鍵の歯が刃に食いこみ、火花、鎖がきしむ、足が床を削る。突き放してから最後）、最後のひと振り（鍵を背中まで回し両手で赤。弾ききると打ち返しの一閃がぬしの背後まで斬り抜け、ぬしがよろめく）、くずし斬り（弾けないと剣がはね上げられ、締まりがほどけ、鍵を横に引いて赤で薙ぐ）。暗い門のぬしは、触手が鍵を持ち上げる・押し合いを締めつけるなどが加わり、さらに触手の合（金・横から巻きこむ）と重い合（赤・深く引いて止まる突き）がある。

## 大ボスの待機（第2版）
  - 門番：剣先で床を二度叩き、肩越しに背後の門をふり返って、閉じているのを確かめる。
  - 門のぬし：鍵の先を床に下ろし、半歩さがって半歩出るのを二度。鍵が床をこすって火花。
  - 暗い門のぬし：背中の触手が兜の耳もとへ寄り、ぬしは首をかしげてささやきを聞く。

## 資料集の見せ方と、モーションの種類（第2版）
  - 門番：体は押されても、交差した剣はほどかない。立ち直ると剣どうしが鳴って構えに戻る。
  - 黒い門番：傷から紫のふちの黒いくらやみがしみ出し、背中の触手が反射で跳ねる（光らない）。
  - 門のぬし：ほとんど下がらず、足が床を削り、二太刀目は腰を沈めて受ける。傷は封印のひびへ向かい、くらやみの筋が走る。
  - 暗い門のぬし：傷が裂けてくらやみが噴き、細い触手が三本はじけ、奥で赤い目が一瞬開く。

## パリィされとブレイク（第2版）
- 門番（済）：交差の剣は「閉じた門」。小は前の剣だけがはね上がる。大は二本の剣が上へこじ開けられ、腕が大きく開いてのけぞり、交差に戻ると「キン」。ブレイクは交差がほどけたまま、二本の剣が両脇に垂れ、ひざが落ち、頭が垂れる（門がはじめて開いた姿）。立て直しは二本を一気に振り上げて交差、「キン」。
- 黒い門番（済）：門番と同じ崩れ方。こじ開けられた胸の隙間から、くらやみが漏れる（ブレイク中はずっと。閉じると止まる）。
- 門のぬし（済）：振りは門番と同じ二段（鍵ははね上がって戻りが遅い）。赤い突きをそらされると前へつんのめりかけるが、手首の鎖が張って半歩で止まる（つながれている印）。ブレイクは鍵の先が床まで落ち、頭が垂れる。立て直しは鍵を一気に引き上げ、大きく行き過ぎて収まる。
- 暗い門のぬし（済）：鍵ははね上がる、触手は弾かれると縮んで腕へ逃げこみ、腕ごと後ろへはじかれる（部位で崩れ方を分ける）。ブレイクは触手の腕がだらりと垂れて勝手にひくつき、胸のひびからくらやみ。立て直しは、ぬし自身ではなく背中の触手が鍵の腕を持ち上げる。

## 見直し（第2版、資料集を見ての直し）
- 門番が黒い門番になる場面：背中の下（門のある側）から、侵食の前線が距離で広がる。はじめゆっくり、だんだん速い。前線の先を細い黒い筋が走り、のまれたところは黒い門番の鋼の色になって黒紫の筋が浮く（金のふちは紫に、紺の前垂れは暗く）。全身がのまれたら、白く光らせずに粒で黒い門番の絵へ溶けかわり、兜の目が一つずつ開く。交差の構えは最後までほどかない。
- 門番の二連撃（黒い門番のくさった二連撃も同じ）の後ろの腕：ひじと手首を人の曲がる向き（ひじ 0〜+0.6、手首 +0.45〜+0.6）のまま動かす。交差をほどくときは、前を通って剣先を下ろす。二撃目の構えは、腕を後ろから頭上へ上げ、剣を肩の後ろへ寝かせる（兜に腕を重ねない）。振りは頭上を越えて前下へ（頭上の前を通るキーをはさむ）。一撃目の当たりで後ろの腕が交差の位置へ飛ばないよう、全部のキーに後ろの腕の値を書く。
