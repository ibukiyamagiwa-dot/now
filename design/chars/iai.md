# 居合の剣士・居合のおかしら

敵ごとの細部（見た目・技・モーション・パリィされ・ブレイクなど）。原則・作風・世界観・全員に通じる決まりは `design/DECISIONS.md` にあり、それを前提にする。決まったことだけを書く。

## 居合の剣士・居合のおかしら（第2版、中ボスとモブの三組目）
- 人を斬るために降りてきた者たち（純粋な悪）。斬った者をくらやみに差し出し、力をもらっているつもりでいる。くらやみの側は気にも留めていない。「力」はただの浸食。
- 見た目：人型の剣士の骨格（`v2/iai.js`）。深い笠で顔は見えず、笠の下に光らない暗い目が二つ。藍の着物と帯。刀はいつも鞘の中で、抜くのは斬る一瞬だけ。刀を持つ右腕が黒い（浸食）：モブは手首から肘まで、おかしらは肩まで＋首に筋。おかしらは1.25倍で、鞘に斬った数だけ刻み。
- 合図は笠の下の目に出る（本気の赤い騎士の「目の光の居合」を、ここで先に教わる）。
- 技：モブは「居合」「返しの構え→返し斬り（赤）」。おかしらは＋「二の太刀」。
  - 居合：腰を落として柄に手をかけて止まる。待つ長さは短いときと長いとき（ゲームの12F／30F）。目が白く光ってから28Fで一閃（途中は描かない）。斬ったまま残心→血振り→チンと納める。
  - 返しの構え：居合の構えより深く沈み、鯉口を切って鞘の口から刃が少し見える（居合の構えとの違いはこの銀色。本気の赤い騎士と同じ決まり）。斬りかかると鞘で受け流され、目が赤く光って28Fで抜きざまの斬り上げ（赤）。弾けば居合返し（ブレイク）。まほうなら構えを崩せる。
  - 二の太刀（おかしらだけ）：居合の構えより低く、左手で鞘を背中へ大きく引き上げて止まる（鞘引き）。目が光り、一閃→斬った形で止め→頭上へ返して止め→真上から打ち下ろし。二度目の光は打ち下ろしの28F前で、頭上で止まっている間に、頭上の刀の先に出る（刀はもう抜けているので目ではない。2026-11-25）（一閃から打ち下ろしまで44F。2026-11-25）。一閃から頭上へは、刀を前から上へ返す（背中側を回さない。2026-11-26）。構えで「一太刀か二太刀か」が分かる。
- 腕を上げる動き（ひまなときの手、出現の笠、返し斬りの血振り、二の太刀の頭上）は、腕と刀を体の前を通して動かす（背中側を回さない。2026-11-26）。
- 待機：モブは黒い右手を顔の前で握っては開いて眺め、肩を揺らして笑う。おかしらは鞘を傾けて刻みを一つずつなぞり、数え終えると主人公を見る（次の刻み）。光らない。
- 出現：構えずに歩いてきて止まり、笠のふちを指で上げて値踏みし、下ろして待つ。
- パリィされ：刀ごと腕がはね上げられてのけぞり、笠がはね上がって黒い筋の走った顔がのぞく（弾いた者だけのごほうび）。二の太刀の一太刀目（小）は、はね上がった刀をそのまま頭上へ返して二太刀目へつなぐ。
- ブレイク：居合返しで構えが崩れる。抜き身の刀が床近くまで垂れ、鞘は腰からずれ、笠が傾いたまま肩で息をする（刀が鞘の外にある＝居合ができない＝すき）。立て直しは一瞬で納刀（チン）して居合の構え。
- やられ：のけぞって笠がはね上がる。傷から出るのは血ではなく黒いもの（腕と同じ浸食）。
- 撃破：ひざをつき、笠が落ちる。右腕の黒が一気に全身へ広がり、下から崩れて消える。床には笠だけが残る（くらやみは迎えにも来ない）。
- 覚悟の段：浸食が広がる段階。着物の色（藍→赤→黒→紫）、黒が肩・首・胸へ（おかしらは一段先）、黒い段から笠のふちがほつれ、紫の段で笠の下と黒い腕に光らない目が増える（おかしらは一段先なので、腕の目は黒い段から。笠の下の目は、どちらも紫の段から）。

## 数値（2026-11-26 確定。`v2/iai.js` と一致。撃破は `v2/ko2.js` が長さを詰めて芯を足す）
合図から当たりまでは、どれも28F。
- 居合：腰を落として柄に手（10F）→ 目が白く光る 40F → 一閃 68F。構えてから光るまでの長さは揺らす（ゲームの12F／30F。`DECISIONS.md` の例外「居合の待つ長さ」）。資料集のカードは30F。
- 返し斬り：返しの構えに斬りかかられ、鞘で受け流しながら深く沈む（20〜28F）→ 沈みきって目が赤く光る 28F → 抜きざまの斬り上げ 56F（赤、軌跡は直線）。予兆の間は沈んだまま待つ。
- 二の太刀（おかしら）：目が白く光る 28F → 一閃 56F → 頭上へ返して止まる → 頭上の刀の先が白く光る 72F → 打ち下ろし 100F。間44F（ゲームの【連撃の間】居合のおかしら：二の太刀＝44）。二度目の合図は一閃の16F後で、当たりと重ならない。二の太刀は待つ長さを揺らさない（構えてから光るまで18F。揺らすのは居合だけ）。
- 撃破：モブ96F・おかしら110F。最後の一撃の14F後に閃光、かけらは浸食の黒い粒（`v2/ko2.js`）。
