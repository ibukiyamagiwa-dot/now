# チケット

2023-04-11「チケットでタスク管理」にならう。仕事は1つずつチケットにし、持っている人（セッション）が作業する。状態を見れば、何が済んで何が止まっているかが一目で分かる。

- **1枚1ファイル**（`T001_題.md`）。並んで作業するセッションが同じファイルをいじらないため（2023-12-12「多くの人がファイルをいじる方法」）。
- **大きさ**：1〜2セッションで「済み」にできる大きさに切る。1体の敵は、桜井氏の「企画・モデル・モーション・プログラム・エフェクト・調整」のように、絵（骨組み）→ 技・動き → やられ・演出 → 出現・ひまなとき、の段に分ける。
- **前**：先に済んでいないと始められないチケットだけを書く。直列にしすぎない（「あまり直列にしない方が良い」）。
- **済んだチケットは消さない**（完了をストックする、2024-04-16「デバッグの体制」）。
- **バグもチケットにする**。種類をバグにし、ランクをつける（A＝止まる・こわれる／B＝遊びが変わる・進めない／C＝見た目だけ）。再現の手順（`tests/soak.mjs` の敵・種・フレームなど）を書く。

## 状態
まだ・進行中・済み・保留・やめた の5つ（桜井氏の挙げる進行中・完了・保留・破棄に「まだ」を足した）。
- 取るとき：状態を「進行中」にし、持ち場と始めた日を書いてコミットする。7日を超えて進行中のままなら `node tools/tickets.mjs` に出る（ずるずる続けない。2024-10-08「ディレクターは切る仕事」）。
- 済んだら：状態を「済み」にし、済んだ日を書く。依頼の一覧の節の状態も直す（節のチケットが全部済めば節も済み）。
- 保留：「- 決めること：…　案：A／B（おすすめ）」を書く。`node tools/handan.mjs` の判断待ちに出る。

## 形
```
# T006 影の剣士に骨組みを広げる
- 節：影の剣士・うそつきの影
- 種類：作業
- 状態：まだ
- 持ち場：game
- 前：なし
- 重さ：中
- 始めた日：
- 済んだ日：

## すること
- …

## 済みの条件
- …
```
節が2つ以上なら「／」で区切る。`node tests/tickets.mjs` が形と、依頼の一覧の状態とのずれを見る。次に取れるチケットは `node tools/tickets.mjs`。
