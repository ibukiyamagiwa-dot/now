## すること
確定した資料集（2026-11-26）に合わせて、主人公を資料集の骨組みで描く。門番と同じく、まず URL に `?new` をつけたときだけ（`js/24h-hero.js`）。
- 見本：`design/chars/hero.md`（「見直し」「主人公のモーション」「数値」の表）、`design/GAME_REQUESTS.md` の「見た目の直し」の主人公の2行と「主人公のモーション」のこうげきの行。絵は `design/v2/specs.js` の `SPEC.hero`・`heroShield`、`design/v2/rig.js` の `knight`、姿勢は `design/v2/hurt.js` の `HUP` `HDN` `HDN2` `HUPS` `HREST`、こうげきのキーは `design/v2/heromv.js` の `HATK` と `heroAtkCard`。
- 構え：肘を曲げて前腕を前へ、剣は手首から立てる（`SPEC.hero.pose`）。待機はゆっくり息（`hh_idle`）。
- 剣：長さ28、刃は手元の銀の一色（`SPEC.hero.w`）。
- 盾：はじまりの盾（鉄のふち、木の面、中央の突起）。差分（傷だらけの盾・開いた門など）はクリアチェッカーのごほうびを入れるときに足す（ここではしない）。
- こうげき3種（`hh_atk` `hh_chase` `hh_heavy`）：振りかぶって止まった瞬間に剣先がうすい青に光り、光ってから【こうげきの光から当たりまでのフレーム】＝20 で当たる。待つあいだは振りかぶったまま（静）、最後の【こうげきの斬り下ろしフレーム】＝6 で斬り下ろす（動）。刃は拳から前腕の続きで前へ、手首を下へ折らない。追撃は斬り上げ（金の×）、重い一撃は振り切って粘る。
- 数値：上の2つを `DEF` に出す（いまは敵の【予兆から着弾までのフレーム】28F を使い、6 は描画の中に直に書いてある）。追撃【追撃の受付】8F・重い一撃【重い一撃の受付】3F は当たりを基準にそのまま。
- ほかの動き（まもる・かいふく・まほう・出現・やられ・撃破）は、`?new` では仮の構え（`heromv.js` の `HP_`）で見せる。描き直しは T082・T083。
